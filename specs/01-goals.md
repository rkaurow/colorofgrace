# Goals

## Alur Utama

**Pendaftaran (publik)**
Link web → masuk web → registrasi → isi nama, asal gereja, tahu acara dari mana, email, nomor WA → submit → pemberitahuan pendaftaran berhasil dan QR Code dikirim via email.

**Hari-H (dua tahap)**
1. **Daftar ulang** — peserta menunjukkan QR Code di layar HP → panitia scan → nama tampil → tercatat hadir → panitia cetak gelang → gelang dipakaikan.
2. **Masuk ruangan** — peserta menunjukkan gelang → panitia scan → nama tampil → tercatat masuk.

**Admin**
Login admin → list peserta dengan semua variabel, tombol kirim ulang QR dan cetak gelang di ujung baris → menu daftar ulang → menu masuk ruangan.

## Sasaran

- Pendaftaran online tanpa perlu akun peserta
- Pengiriman QR Code otomatis melalui email
- Pengiriman ulang QR Code manual oleh admin
- Manajemen dan pencarian data peserta
- Pencetakan gelang berisi QR Code di meja registrasi
- Pencatatan kehadiran dua tahap beserta waktunya
- Antarmuka responsif untuk ponsel dan desktop
